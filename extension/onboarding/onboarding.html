SLAB Agent

Self-Learning Agent Browser · Hackathon Edition

🔮

Floating Orb & Voice Navigation

SLAB attaches a lightweight, non-intrusive floating Orb to the bottom-right of every allowed web page. Say "scroll down", "go back", or "click search" for hands-free browsing.

⌨️

Command Palette (Ctrl + Shift + K)

Press Ctrl+Shift+K (or Cmd+Shift+K on Mac) on any page to summon the spotlight command palette. Filter, auto-complete, and execute commands at deterministic speed.

✨

100% Offline Saliency Summarizer

Say "summarize page" to extract key takeaways and bullet points. The built-in Token Optimizer strips clutter and delivers up to 98% token reduction completely offline!

👁️

Adaptive Reading Gaze Scroll

Equipped with WebGazer webcam eye-tracking. When your eyes reach the bottom of the viewport, the page gently scrolls down matching your natural reading speed.

🛡️

Habit Memory & Access Gating

SLAB automatically remembers which commands you use on which websites and suggests them. High-risk clicks pause for a 6-second confirmation so you're always in complete control.
