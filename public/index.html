Core Philosophy

4-Layer Self-Learning Architecture

Explore once. Learn the workflow. Reuse the command deterministically.

Layer 0
🔭 Explore
Sandboxed Playwright session. Explores unfamiliar websites, inspects DOM elements, and maps network endpoints.
Layer 1
🧠 Learn
Preserves endpoint graphs, authentication cookies, and DOM selector memory for persistent re-use.
Layer 2
🛠️ Adapt
Synthesizes reliable TypeScript CLI adapters with structured -f json output schemas.
Layer 3
⚡ Automate
Instant deterministic execution via webcmd <site> -f json with up to 98% token reduction.
